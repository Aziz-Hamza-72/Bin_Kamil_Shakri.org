# Bin_Kamil_Shakri.org — Front-End Practice Hub

Welcome to **Bin_Kamil_Shakri.org**, a front-end practice workspace featuring vanilla HTML5, CSS3, and JavaScript projects. This repository serves as a showcase for custom web UI/UX components, interactive tools, and web experiments.

---

## 🌟 Key Highlights & Projects

### ⏱️ BK-Watch | BK-StopWatch
A feature-rich web-based timekeeping application designed for precision and visual appeal.
- **SVG-Powered UI:** Built extensively using SVG graphics, providing a crisp, scalable, and responsive user interface across all resolution displays.
- **Myriad UI Options:** Offers diverse aesthetic design modes and styles.
- **Interactive Controls:** Smooth stopwatch start, pause, reset, and lap recording functionality driven by vanilla JavaScript.

### 🧮 Aspirian Calculator
A full-featured web calculator tool housed in its own modular layout (`files/AspirianCalculater/`).
- Customized styling and emblems (`emblem.jpg`, `emblem1.png`, `emblem2.png`).
- Clean user interface and isolated logic using `main.html`, `main.css`, and `main.js`.

### 🗂️ Interactive Tabs & Hub
- Integrated navigation structure featuring tabs to easily switch between the **BK-Watch / StopWatch**, **Aspirian Calculator**, and site pages (`about.html`).
- Embedded ad banners and dynamic script wrappers (`files/ads/`).
- Custom audio elements and dynamic visual effects (e.g., animated sound waves).

## 🚀 Running Locally

Because this project uses vanilla web technologies, no build tools or package installation are required!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/Bin_Kamil_Shakri.org.git
   cd Bin_Kamil_Shakri.org
   ```

2. **Launch directly in your browser:**
   - Double-click or open `files/about.html` or `files/AspirianCalculater/index.html` in any modern web browser (Chrome, Firefox, Edge, Safari).

3. **Or run via local development server (Recommended for local media loading):**
   ```bash
   # Using Python 3
   python -m http.server 8000
   ```
   Navigate to `http://localhost:8000/files/about.html` in your browser.
